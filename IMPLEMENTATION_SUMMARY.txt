### visados.py
Location: pipelines/citysignal/adapters/visados.py

Manifest:
- source_id: visados
- publisher: Ministerio de Transportes y Movilidad Sostenible
- cadence: monthly
- geo_level: province
- formats: xlsx
- redistributable: true

Key Methods:
- discover(): Attempts to fetch ministry listing page, parse HTML for Excel links
- parse(): Opens Excel files, extracts data rows
- normalize(): Converts to CanonicalRecord with prov-NN geo_ids

Discovery Strategy (in order):
1. Fetch ministry's statistics page
2. Parse HTML for "visado" + Excel file links
3. Fall back to direct URL patterns
4. Test direct URLs and return first working one

URLs Attempted:

- https://transportes.gob.es/vivienda-estadisticas (simplified)
- https://www.transportes.gob.es/recursos_web/estadisticas/visados-mensual.xlsx (direct)
- https://www.transportes.gob.es/estadisticas/visados/visados-series-provinciales.xlsx (direct)

Data Validation:
- Parses flexible column layouts (varies by ministry releases)
- Handles province codes 1-52 with zero-padding
- Validates month range 1-12
- Filters negative values
- Requires min_rows: 2 (header + data)

Sanity Check Required:

in Spain and proves you have the correct dataset. If your data doesn't show this collapse,
you have the wrong table.

### notariado.py
Location: pipelines/citysignal/adapters/notariado.py

Manifest:
- source_id: notariado
- publisher: Consejo General del Notariado
- cadence: monthly
- geo_level: province
- formats: xlsx, xls
- redistributable: true

Key Methods:
- discover(): Attempts multiple notariado.org URLs, tries direct URLs
- parse(): Loads Excel files from all sheets
- normalize(): Emits both notary_sales and notary_price_m2 records

Discovery Strategy (in order):
1. Try multiple notariado.org sub-paths (statistics, datos-estadísticos, etc.)
2. Parse HTML for CIEN-related Excel links
3. Fall back to direct URL patterns
4. Test and return first working URL

URLs Attempted:
- https://www.notariado.org/es-ES/notariado/estadisticas/cien
- https://www.notariado.org/cien
- https://www.notariado.org/es-ES/datos-estadisticos
- https://www.notariado.org/portal/estadisticas
- https://www.notariado.org/cien-estadisticas.xlsx (direct)
- https://www.notariado.org/datos/cien-series.xlsx (direct)
- https://www.notariado.org/estadisticas/cien-provincial.xlsx (direct)

Province Mapping:
Handles CIEN's province naming (all uppercase, accents removed per CIEN):
- MADRID → 28, BARCELONA → 08, VALENCIA → 46, MALAGA → 29
- SEVILLA → 41, ILLES BALEARS → 07, BIZKAIA → 48, ZARAGOZA → 50

Data Output:
For each province/month, emits TWO records:
1. notary_sales: transaction count (0-40,000 typical range)
2. notary_price_m2: price per square metre (200-8,000 EUR typical range)

Sanity Checks:
- Madrid and Barcelona should have highest €/m² values
- Monthly sales per province typically in thousands
- Price progression should show real market trends
